# Ali Hassan Abbas — Personal Portfolio

This repository contains the source for my personal portfolio website, published with GitHub Pages.

## Local preview

Open `index.html` in a browser. The site is a static, responsive HTML/CSS page and requires no build tools or dependencies.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. GitHub Pages should publish the site at [https://alihassanabbas.github.io](https://alihassanabbas.github.io).

The site links to selected public projects, LinkedIn, YouTube, and mrelan.com. Update the project list as repositories evolve.
